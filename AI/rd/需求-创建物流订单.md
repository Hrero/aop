# 创建物流订单页面需求说明

## 1. 页面概述

创建物流订单页面用于填写和提交新的物流订单信息，包括发货信息、收货信息、中转信息和货物信息等。页面采用表单布局，通过清晰的分区展示各项信息，支持添加中转站点和货物明细。

## 2. 页面结构

页面分为五个主要部分：
1. 发货信息区域
2. 收货信息区域
3. 中转信息区域
4. 货物信息区域
5. 底部操作区域

## 3. 功能模块详细说明

### 3.1 发货信息区域

| 业务线 | 所属业务线 | 下拉选择框 | 是 | - |

| 业务类型 | 选择业务类型 | 下拉选择框 | 是 | - |
| 运输方式 | 选择运输方式 | 下拉选择框 | 是 | - |
| 其他物流服务 | 其他物流服务选项 | 下拉选择框 | 否 | 标注"可多选" |
| 计划物流运输车型 | 物流运输车型 | 下拉选择框 | 否 | 标注"可多选" |

## 4. 数据交互

### 4.1 数据获取

通过接口获取各个下拉框的数据：
- 优先级列表
- 业务线列表
- 运输模式列表
- 业务类型列表
- 运输方式列表
- 其他物流服务选项列表
- 计划物流运输费率列表
- 省市区县列表
- 合/厂/拉地址列表
- 货物类型列表
- 货物名称列表

### 4.2 操作交互

表单页面提供以下功能按钮：
- 增加中转站明细：点击后添加新的中转站点信息区块
- 删除中转站明细：点击后删除对应的中转站点信息
- 增加电单车货物明细：点击后添加新的电单车货物行
- 删除电单车货物明细：点击后删除对应的电单车货物行
- 增加电单车备件明细：点击后添加新的电单车备件行
- 删除电单车备件明细：点击后删除对应的电单车备件行
- 导入表格：点击后可导入电单车备件信息
- 导入SKU：导入指定SKU信息
- 保存：保存当前填写的订单信息
- 提交：提交物流订单信息

## 5. 表单验证

表单需要进行以下验证：
- 必填字段不能为空（以红色星号标记）
- 手机号码格式验证
- 文本输入框长度限制
- 数字输入框范围限制

## 6. 提示信息

页面提供以下提示信息：
- 中转信息区域：系统串联中转站顺序的说明
- 中转站点限制：最多可添加5个中转站点
- 输入框字符限制：如备注最多500字符
- 必填字段标记：使用红色星号标记

## 7. UI规范

### 7.1 布局与分区
- 页面标题"新增物流订单"居中显示
- 页面采用垂直分区，各个信息区域之间有明确分隔
- 每个区域有清晰的标题（发货信息、收货信息、中转信息、货物信息）
- 表单控件对齐，保持一致的间距和布局

### 7.2 控件样式
- 必填项标记：红色星号(*)
- 下拉选择框：统一样式，带有下拉箭头
- 按钮样式：主要按钮使用蓝色，次要按钮使用白色底蓝边
- 删除按钮：使用红色突出显示

### 7.3 交互反馈
- 表单验证错误时，在对应字段下方显示错误提示
- 表单提交成功时，显示成功提示并清空或保留表单
- 表单提交失败时，显示错误提示并保留已填写的内容
